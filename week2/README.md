# Interactive Task Manager

## Project Description

A feature-rich task management application built with HTML, CSS, and JavaScript.

---

## Features

- Add Tasks
- Edit Tasks
- Delete Tasks
- Mark Tasks Complete
- Filter Tasks
- Task Statistics
- Dark/Light Mode
- localStorage Support
- Responsive UI

---

## Technologies Used

- HTML5
- CSS3
- JavaScript
