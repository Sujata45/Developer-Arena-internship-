# Interactive Task Manager

## Project Description

Interactive Task Manager is a feature-rich task management web application built using HTML, CSS, and Vanilla JavaScript. The application allows users to efficiently manage daily tasks with features such as adding, editing, deleting, completing, filtering, and storing tasks using localStorage.

The project focuses on DOM manipulation, event handling, array operations, local storage, and responsive web design concepts.

---

# Project Objectives

The main objectives of this project are:

- To understand JavaScript DOM manipulation
- To implement CRUD operations using JavaScript
- To practice event handling techniques
- To use localStorage for data persistence
- To create a responsive user-friendly interface
- To implement filtering and task statistics
- To improve frontend development skills

---

# Features

- Add Tasks
- Edit Tasks
- Delete Tasks
- Mark Tasks as Complete/Incomplete
- Filter Tasks (All / Active / Completed)
- Data Persistence using localStorage
- Drag and Drop Task Reordering
- Dark/Light Theme Toggle
- Task Statistics and Analytics
- Responsive User Interface
